SeaCraft: hull design and naval architecture

START
  Linux:    run ./seacraft-gui
  Windows:  double-click seacraft-gui.exe
  macOS:    drag SeaCraft to Applications, then open it

  Keep this folder together: it holds the licences that must travel with the programs. On macOS
  they are inside the app, in SeaCraft.app/Contents/Resources.
  To begin, choose "Open an example" on the start screen. The same hulls are in examples/ as files.
  seacraft is the command line; run it with --help. It is seacraft.exe on Windows, and on macOS
  SeaCraft.app/Contents/MacOS/seacraft.

WINDOWS
  The Windows programs are not signed, so SmartScreen may warn you the first time. Choose
  "More info", then "Run anyway", if you trust where you downloaded this from. The Windows build is
  only compiled and tested automatically: nobody has opened this GUI on Windows by hand yet.
  Please report what you find.

MACOS
  The app is not signed with an Apple Developer ID or notarised, so macOS refuses to open it the
  first time. If you trust where you downloaded this from, open System Settings > Privacy & Security
  and choose "Open Anyway". The macOS build is only compiled and tested automatically: nobody has
  opened this GUI on a Mac by hand yet. Please report what you find.

NOT VALIDATED
  Most calculations have not been checked against tank tests, sea trials or approved software, and
  results may be wrong. A PASS against a criterion is not approval. Do not rely on SeaCraft for
  design or safety decisions without independent checks by a qualified person. See DISCLAIMER.md.
