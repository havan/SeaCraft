SeaCraft

Model a ship’s hull, then measure it: hydrostatics, stability, resistance, motions and lines plans. Free software in Rust, with a desktop app, a command line and an MCP server. It opens and saves FREE!ship .fef files.

Results are not validated.

Most calculations have not been compared with tank tests, sea trials or approved software, and they can be wrong even when they look right. A PASS against a criterion is arithmetic, not an approval. Have a qualified person check anything you rely on. What has been checked, and the full disclaimer.

A hull is a control net. Pull one point and the surface follows.

SeaCraft models a hull the way FREE!ship does: a coarse net of points refined into a smooth subdivision surface, with creases where a chine or a stem needs a hard edge. There are no NURBS patches to keep in step.

You work in four linked views: perspective, profile, plan and body plan. Hydrostatics update when you let go of a point, and undo goes back 64 steps. Autosave can bring your work back after a crash.

From lines to numbers, for the selected hull

The steps below follow one hull through the program. Every number comes from SeaCraft, and the commands get you the same numbers. Choosing another hull at the top of the page changes all of them.

  1. Cut the lines

    Stations, buttocks and waterlines are cut from the refined surface and exported as SVG, DXF or IGES. Curvature combs show you where a line is unfair.

  2. Measure the hydrostatics

    Volume, displacement, centres, coefficients and metacentres are integrated over the panels of the refined mesh, at any draft, trim and heel. The curve shows how the underwater volume is spread along the length.

  3. Check the stability

    Cross curves and righting levers past 90° of heel, with free trim. Add loading conditions with tanks and free-surface correction, lost-buoyancy damage cases, and the IMO intact and weather criteria as arithmetic on these numbers.

  4. Estimate the resistance

    Holtrop and Mennen for displacement ships, Michell thin-ship theory, the Delft series for yachts and Savitsky for planing hulls. An optimiser can then adjust Cp, LCB and L/B for a target speed.

  5. Predict the motions

    Strip-theory heave and pitch in regular head waves, then irregular seas, significant motions and motion sickness incidence.

  6. Hand it on

    A self-contained HTML report collects the measurements. Meshes and curves go out as OBJ, STL, 3MF, PLY, IGES and DXF for CAD and 3D printing, and developable plates unfold to SVG.

Let an AI agent work on the hull

seacraft mcp is a Model Context Protocol server. An agent can load a hull, move control points, measure, render a picture and save, using the same code the desktop app runs.

Point it at a running modeller and you watch the edits happen. That connection stays on your own machine and needs a token by default, and you can limit which folders it reads and writes.

The repository includes skills that teach an agent to reach design targets, fair a hull and report stability. They tell it to re-measure after each change, and to look at a render instead of guessing from coordinates.

Work on a file, with edits held until the agent saves:

claude mcp add seacraft -- seacraft mcp --open hull.fef

Or drive a modeller you can see:

seacraft-gui --control 127.0.0.1:7878 --open hull.fef
claude mcp add seacraft -- seacraft mcp --connect 127.0.0.1:7878

Build it from source

There are no prebuilt binaries yet. You need rustup, which installs the pinned Rust version for you. On Linux the desktop app also needs the usual windowing libraries.

The current version is {{version}}. Anything may change while it is 0.x.

Open the app with an example hull:

git clone https://github.com/havan/SeaCraft
cd SeaCraft
cargo run --release -p seacraft-gui -- --open examples/trawler-22m.fef

Or measure from the command line:

cargo run --release --bin seacraft -- hydro examples/trawler-22m.fef --kg 2.5
Linux libraries (Ubuntu) 
sudo apt-get install libxkbcommon-dev libwayland-dev libegl1-mesa-dev \

How far the numbers have been checked

Compared with

  • Closed-form cases, such as box barges.
  • Separate scripts written for this project. Many of their reference numbers are not published values.
  • SeaCraft’s own earlier output. The demo hull’s numbers only catch unintended changes, and say nothing about whether they are right.

Not systematically compared with

  • Tank tests.
  • Sea trials or other full-scale measurements.
  • Approved naval-architecture software.

You can help

Comparing a result with published data is the most useful contribution anyone can make. Start with the source of each reference number, then pick a task from the roadmap.
